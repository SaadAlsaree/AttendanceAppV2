# GetOrganizationalSummary - الملخص التنظيمي

## نظرة عامة

ميزة `GetOrganizationalSummary` توفر ملخصاً مختصراً للوحدات التنظيمية يتضمن:

-  عدد الموظفين لكل وحدة
-  عدد الشفتات لكل وحدة
-  عدد الموظفين لكل شفت
-  عدد الحضور الكلي لكل شفت
-  عدد المتأخرين لكل شفت
-  معدلات الحضور والتأخير

## الملفات المكونة

### 1. طبقة التطبيق (Application Layer)

-  **GetOrganizationalSummaryQuery.cs**: معاملات الطلب والفلترة
-  **OrganizationalSummaryVm.cs**: نموذج الاستجابة المختصر
-  **GetOrganizationalSummaryHandler.cs**: الهاندلر الرئيسي للميزة
-  **README.md**: التوثيق الشامل

### 2. طبقة الويب (Web Layer)

-  **GetOrganizationalSummary.cs**: الإندبوينت REST API

## الميزات المقدمة

### 1. ملخص الوحدات التنظيمية (UnitSummary)

لكل وحدة تنظيمية، يتم توفير:

-  معلومات الوحدة (الاسم، الكود، الوحدة الأب)
-  عدد الموظفين الإجمالي
-  عدد الشفتات النشطة
-  إحصائيات الحضور والغياب والتأخير
-  معدل الحضور والتأخير للوحدة

### 2. ملخص الشفتات (ShiftSummary)

لكل شفت، يتم توفير:

-  معلومات الشفت (الاسم، وقت البداية والنهاية)
-  عدد الموظفين في الشفت
-  عدد الحضور والغياب والتأخير
-  معدل الحضور والتأخير للشفت

### 3. الإحصائيات العامة (GeneralSummary)

-  إجمالي عدد الوحدات
-  إجمالي عدد الموظفين
-  إجمالي عدد الشفتات
-  إجمالي الحضور والغياب والتأخير
-  معدل الحضور والتأخير العام

## معاملات الطلب (Query Parameters)

-  **OrganizationalUnitId** (اختياري): معرف الوحدة التنظيمية المحددة
-  **IncludeSubUnits** (اختياري): تضمين الوحدات الفرعية (افتراضي: true)
-  **Date** (اختياري): التاريخ المستهدف (افتراضي: اليوم الحالي)

## مثال الاستخدام

### طلب ملخص لجميع الوحدات

```
GET /reports/organizational-summary
```

### طلب ملخص لوحدة محددة مع الوحدات الفرعية

```
GET /reports/organizational-summary?OrganizationalUnitId=123&IncludeSubUnits=true
```

### طلب ملخص لتاريخ محدد

```
GET /reports/organizational-summary?Date=2024-01-15
```

## حساب النسب المئوية

### معدل الحضور للشفت

```
معدل الحضور = (عدد الحضور / (عدد الحضور + عدد الغياب)) × 100
```

### معدل الحضور للوحدة

```
معدل الحضور = (إجمالي الحضور / (إجمالي الحضور + إجمالي الغياب)) × 100
```

### معدل الحضور العام

```
معدل الحضور العام = (إجمالي الحضور / (إجمالي الحضور + إجمالي الغياب)) × 100
```

## معالجة الأخطاء

-  **الوحدة غير موجودة**: يتم إرجاع خطأ `NotFound` إذا لم يتم العثور على الوحدة التنظيمية المحددة
-  **أخطاء عامة**: يتم التقاط أي استثناءات وإرجاع رسالة خطأ مناسبة
-  **معالجة التواريخ**: تحويل جميع التواريخ إلى UTC لتجنب مشاكل PostgreSQL

## الأداء والتحسينات

-  استخدام `AsNoTracking()` لتحسين الأداء
-  فلترة البيانات في قاعدة البيانات بدلاً من الذاكرة
-  حساب النسب المئوية بشكل دقيق مع التقريب إلى رقمين عشريين
-  دعم `CancellationToken` للعمليات الطويلة
-  معالجة صحيحة للتواريخ مع PostgreSQL
