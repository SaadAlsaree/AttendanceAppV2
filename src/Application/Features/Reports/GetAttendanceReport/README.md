# تقرير الحضور الشامل (GetAttendanceReport)

## نظرة عامة

ميزة تقرير الحضور الشامل توفر إحصائيات مفصلة وشاملة عن حضور الموظفين في الوحدات التنظيمية المختلفة، مع إمكانية الفلترة حسب الشفتات والفترات الزمنية.

## الملفات المكونة للميزة

### 1. طبقة التطبيق (Application Layer)

-  **GetAttendanceReportQuery.cs**: معاملات الطلب والفلترة
-  **AttendanceReportVm.cs**: نموذج الاستجابة الشامل
-  **GetAttendanceReportHandler.cs**: الهاندلر الرئيسي للميزة
-  **README.md**: التوثيق الشامل

### 2. طبقة الويب (Web Layer)

-  **GetAttendanceReport.cs**: الإندبوينت REST API
-  **README.md**: توثيق الإندبوينت

## الميزات المقدمة

### 1. الإحصائيات العامة (GeneralStatistics)

-  **عدد الموظفين الإجمالي**: إجمالي عدد الموظفين في الوحدة المستهدفة
-  **عدد الشفتات**: إجمالي عدد الشفتات النشطة
-  **عدد الحضور**: عدد الموظفين الحاضرين
-  **عدد الغياب**: عدد الموظفين الغائبين
-  **عدد التأخير**: عدد الموظفين المتأخرين
-  **عدد الانصراف المبكر**: عدد الموظفين الذين انصرفوا مبكراً
-  **عدد العمل الإضافي**: عدد الموظفين الذين لديهم ساعات عمل إضافي
-  **عدد غير مسجلين الدخول**: عدد الموظفين الذين لم يسجلوا دخول
-  **عدد غير مسجلين الخروج**: عدد الموظفين الذين لم يسجلوا خروج
-  **عدد الإجازات**: عدد الموظفين في إجازة

### 2. إحصائيات الشفتات (ShiftStatistics)

لكل شفت، يتم توفير:

-  معلومات الشفت (الاسم، وقت البداية والنهاية)
-  عدد الموظفين في الشفت
-  إحصائيات الحضور والغياب والتأخير
-  النسب المئوية لكل مؤشر

### 3. إحصائيات الوحدات الفرعية (SubUnitStatistics)

لكل وحدة فرعية، يتم توفير:

-  معلومات الوحدة (الاسم، الكود)
-  إحصائيات شاملة مشابهة للإحصائيات العامة
-  النسب المئوية لكل مؤشر

### 4. إحصائيات الإجازات (LeaveStatistics)

-  **إجمالي الإجازات**: عدد الإجازات الكلي
-  **الإجازات المعتمدة**: عدد الإجازات المعتمدة
-  **الإجازات قيد الانتظار**: عدد الإجازات قيد الانتظار
-  **الإجازات المرفوضة**: عدد الإجازات المرفوضة
-  **إحصائيات حسب نوع الإجازة**: تفصيل لكل نوع إجازة

## معاملات الطلب (Query Parameters)

```csharp
public sealed class GetAttendanceReportQuery
{
    public Guid OrganizationalUnitId { get; set; }     // الوحدة التنظيمية المستهدفة
    public DateTime? StartDate { get; set; }           // تاريخ البداية (اختياري)
    public DateTime? EndDate { get; set; }             // تاريخ النهاية (اختياري)
    public Guid? ShiftId { get; set; }                 // فلترة حسب شفت معين (اختياري)
    public bool IncludeSubUnits { get; set; } = true;  // تضمين الوحدات الفرعية
}
```

## مثال على الاستخدام

```csharp
var query = new GetAttendanceReportQuery
{
    OrganizationalUnitId = Guid.Parse("unit-id"),
    StartDate = DateTime.Today.AddDays(-30),
    EndDate = DateTime.Today,
    IncludeSubUnits = true
};

var result = await handler.Handle(query, cancellationToken);
```

## النسب المئوية المحسوبة

### الإحصائيات العامة

-  **معدل الحضور**: (عدد الحضور / إجمالي الموظفين) × 100
-  **معدل الغياب**: (عدد الغياب / إجمالي الموظفين) × 100
-  **معدل التأخير**: (عدد المتأخرين / إجمالي الموظفين) × 100
-  **معدل الانصراف المبكر**: (عدد المنصرفين مبكراً / إجمالي الموظفين) × 100
-  **معدل العمل الإضافي**: (عدد من لديهم عمل إضافي / إجمالي الموظفين) × 100
-  **معدل الإجازات**: (عدد الإجازات / إجمالي الموظفين) × 100

### إحصائيات الإجازات

-  **معدل الاعتماد**: (الإجازات المعتمدة / إجمالي الإجازات) × 100
-  **معدل الرفض**: (الإجازات المرفوضة / إجمالي الإجازات) × 100
-  **معدل الانتظار**: (الإجازات قيد الانتظار / إجمالي الإجازات) × 100

## معالجة الأخطاء

-  **الوحدة غير موجودة**: يتم إرجاع خطأ `NotFound` إذا لم يتم العثور على الوحدة التنظيمية
-  **أخطاء عامة**: يتم التقاط أي استثناءات وإرجاع رسالة خطأ مناسبة
-  **معالجة التواريخ**: تحويل جميع التواريخ إلى UTC لتجنب مشاكل PostgreSQL

## الأداء والتحسينات

-  استخدام `AsNoTracking()` لتحسين الأداء
-  فلترة البيانات في قاعدة البيانات بدلاً من الذاكرة
-  حساب النسب المئوية بشكل دقيق مع التقريب إلى رقمين عشريين
-  دعم `CancellationToken` للعمليات الطويلة
-  معالجة صحيحة للتواريخ مع PostgreSQL

## التكامل مع النظام

-  متوافق مع نظام الحضور والانصراف
-  متكامل مع نظام الإجازات
-  يدعم التسلسل الهرمي للوحدات التنظيمية
-  متوافق مع نظام الشفتات

## الإندبوينت REST API

### المسار

```
GET /reports/attendance-summary
```

### المعاملات

-  `OrganizationalUnitId` (مطلوب): معرف الوحدة التنظيمية
-  `StartDate` (اختياري): تاريخ البداية
-  `EndDate` (اختياري): تاريخ النهاية
-  `ShiftId` (اختياري): فلترة حسب شفت معين
-  `IncludeSubUnits` (اختياري): تضمين الوحدات الفرعية

### الأمان

-  يتطلب مصادقة (Authentication)
-  يتطلب تفويض (Authorization)

### التوثيق

-  متوفر في Swagger UI
-  يدعم OpenAPI 3.0
